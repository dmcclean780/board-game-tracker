# 0001. Monorepo with frontend, backend and db components

- Status: accepted
- Date: 2026-11-21

## Context and problem statement

One developer, three tightly coupled components.

## Decision

Single repo with `frontend/`, `backend/` and `db/`, each with its own `docs/` and tests, plus root `docs/`.

## Consequences

See the related component docs. Revisit by superseding this ADR with a new one.
