# 0002. Expo (React Native) for Android, iOS and web

- Status: accepted
- Date: 2026-11-21

## Context and problem statement

We need Android, iOS and web from one codebase.

## Decision

React Native with Expo (TypeScript) and react-native-web. Jest + React Native Testing Library for unit tests, Playwright for web integration tests. Mobile-native E2E (Maestro) is deferred.

## Consequences

See the related component docs. Revisit by superseding this ADR with a new one.
